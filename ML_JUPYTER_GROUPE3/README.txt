ML GROUPE 3 - JUPYTER

1. Décompresse ce dossier dans :
   C:\Master_1_projets\TP_NETLOGO_GROUPE3_FINAL_CORRIGE\

2. Le fichier dataset_trafic_ml.csv peut rester dans le dossier parent.
   Le notebook le recherche automatiquement.

3. Ouvre :
   ML_JUPYTER_GROUPE3\ML_Trafic_Groupe3.ipynb

5. Les résultats seront créés dans :
   ML_JUPYTER_GROUPE3\resultats_ml\

Si CatBoost manque dans le noyau Jupyter, exécute :
   %pip install catboost
puis redémarre le kernel et relance le notebook.
