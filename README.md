# Gestion intelligente du trafic routier

Projet de Système Multi-Agents réalisé avec NetLogo et Machine Learning.

## Objectif
Simuler le trafic routier, comparer une gestion classique et intelligente des feux, puis prédire la congestion 20 ticks à l'avance.

## Technologies
- NetLogo
- BehaviorSpace
- Python
- Jupyter
- CatBoost
- Random Forest

## Données
Le dataset principal est généré avec BehaviorSpace à partir de 240 simulations.

## Modèles
Deux modèles sont comparés :
- CatBoost
- Random Forest

## Résultats
- CatBoost : Accuracy 92,50 %, F1 Macro 80,47 %
- Random Forest : Accuracy 91,40 %, F1 Macro 77,37 %
